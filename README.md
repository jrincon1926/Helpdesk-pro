# HelpDesk Pro

A help desk ticket management application built as a software engineer portfolio project

## Overview

Helpdesk Pro aims to simplify IT support ticket registration and tracking. The project is being developed incrementally, starting with a web interface and evolving toward a Java backend, 

## Current features

- Ticket creation through a web form. 
- Ticket priority selection. 
- Display of registered tickets. 
- Responsive interface for different screen sizes.

## Getting started 

1. Clone this repository
2. Open the project folder. 
3. Open `index.html in a browser.

No backend or database setup is currently required for the frontend version.
